# v1.0 Balance Airdrop to v1.1

**Status:** Current process. This replaces the earlier disposal-address / email migration process.

---

## Summary

- Balances from the **v1.0 snapshot at block 434,881** are airdropped to the **same addresses** on the v1.1 chain.
- **Keep your v1.0 `wallet.dat`.** The keys in it also control your airdropped balance on v1.1.
- **Send nothing anywhere.** There is no disposal address and no email registration.
- **Never trust an emailed "disposal address"** or anyone asking you to send coins, your private keys, or your wallet file. That is a scam.
- If your address was missed, a **signed-message claim** is the fallback (see below).
- **There is no deadline.**

---

## What You Do

1. **Back up your v1.0 `wallet.dat`** to offline storage (USB drive, two copies). Do not delete it.
2. Install **v1.1.1** from the official GitHub release (https://github.com/everquin/AMMOcoin/releases/tag/v1.1.1; see [Release Notes v1.1.1](../release-notes/RELEASE_NOTES_v1.1.1.md)).
3. Copy a backup of the v1.0 `wallet.dat` into the v1.1.1 data folder before the first start:
   - Linux: `~/.ammocoin11/`
   - macOS: `~/Library/Application Support/AMMOcoin11/`
   - Windows: `%APPDATA%\AMMOcoin11\`
4. Start the node and let it sync. Your airdropped balance appears on the same addresses you used on v1.0.
5. Check with `ammocoin-cli getbalance` or `ammocoin-cli listunspent`.

If you already have a v1.1.0 wallet with funds, keep that one too. You can import the v1.0 keys into it instead (`dumpprivkey` on the v1.0 wallet, `importprivkey` on v1.1.1) - never paste a private key into a website or send it to anyone.

---

## If Your Balance Is Missing

Only if the snapshot balance for your address does not appear after a full sync:

1. Open your v1.0 wallet (any v1.0 node, offline is fine).
2. Sign a message with the v1.0 address:
   ```bash
   ammocoin-cli signmessage "YOUR_V1.0_ADDRESS" "AMMOcoin v1.1 airdrop claim"
   ```
3. Submit the address, the message and the signature through the official channel announced on the AMMOcoin GitHub repository.

A signature proves ownership without revealing your private key. Nobody legitimate will ever ask for the key itself or for coins.
